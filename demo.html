Cara pakai & catatan teknis

1. File ini mandiri: font sudah ditanam, tanpa CDN, tanpa internet.

2. Tombol rekam memakai canvas.captureStream() + MediaRecorder. Di Chrome Android hasilnya .mp4 kalau didukung, kalau tidak .webm. WebM tetap bisa diupload ke Reels/TikTok/Shorts (semua platform transcode sendiri) — atau konversi cepat: ffmpeg -i in.webm -c:v libx264 -pix_fmt yuv420p out.mp4.

3. Rekaman berjalan real-time (20 detik). Jangan kunci layar / pindah tab saat merekam; encoder bisa drop frame.

4. Tidak ada audio di dalam file — tambahkan audio trending langsung di aplikasi Reels/TikTok/Shorts (lebih aman & lebih naik).

5. Semua klaim di video sengaja jujur: belum ada testimoni, harga sesuai halaman, DP 50%. Jangan diganti jadi angka karangan.
